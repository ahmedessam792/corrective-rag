# Architecture

## Shape

The MVP is a modular monolith with two processes:

```text
React/Vite SPA -> FastAPI -> application services
                              |-- SQLite metadata/event store
                              |-- embedded hybrid retrieval index
                              |-- document parser adapters
                              `-- ModelRuntime -> deterministic dev or Ollama
```

The browser never talks directly to an inference runtime. The backend owns policy and workflow but not model process lifecycle.

## CRAG workflow

```text
retrieve -> evaluate
             | weak and retry available
             v
           rewrite -> retrieve -> evaluate
                                  |
                                  v
                         verify sufficiency
                           |             |
                           v             v
                    structured draft   refusal
                           |
                    citation validation
                           |
                    claim verification
                           |
                    answer / partial / refusal
```

Model output recommends semantic states. Typed deterministic code controls retries, identifiers, routing, context limits, citations, and release policy.

## Persistence

SQLite stores workspaces, documents, chunks, runs, events, answers, and FTS data. Uploaded files live under the configured local data directory. IDs are UUIDs generated by the application. SHA-256 prevents duplicate source ingestion within a workspace.

The embedded retrieval implementation combines FTS5 lexical rank with deterministic local vector similarity through reciprocal-rank fusion. Its interface is intentionally replaceable; the evaluation phase decides whether LanceDB or Qdrant materially improves quality enough to replace it.

## Citation contract

- PDF anchors: document ID, page, optional bounding region, chunk ID, exact passage.
- DOCX anchors: document ID, heading path, paragraph range, chunk ID, exact passage.
- Models may select only candidate citation IDs supplied by the application.
- Unknown IDs, empty passages, or uncited claims fail closed.

## ADRs

- ADR-001: React/Vite SPA; SSR adds no value to a local single-user application.
- ADR-002: explicit typed state machine; current workflow is bounded and does not justify LangGraph.
- ADR-003: SQLite is the source of truth and first embedded retrieval baseline.
- ADR-004: SSE carries replayable semantic progress; query creation and cancellation use HTTP.
- ADR-005: Ollama is the first real runtime candidate; deterministic mode exists only for development/tests.
